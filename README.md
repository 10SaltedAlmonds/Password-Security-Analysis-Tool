The PSAT (Password Strength Analysis Tool) is designed by Noah Wood to analyze and provide feedback on user-generated password. PSAT provides feedback by identifying weeknesses and common vulnerabilities in the password structure. PSAT has the ability to identify the current speed of the CPU, then utilize this speed to simulate a brute-force attack. The attack simulation will return the estimated time for a brute force attack based upon entropy calculations. PSAT was designed as part of a larger project to educate the public on computer compentance and cyber security. 

---FEATURES---
- Password length analysis.
- Password case analysis.
- Number and special character detection.
- Character repetition detection.
- Entropy calculations.
- Estimated brute-force cracking time base on current CPU speed.
- Feedback on ways to improve password security.
